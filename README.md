# Польская кириллица

Веб-транслитератор польского текста по системе из
[`polish_cyrillic_v1.md`](./polish_cyrillic_v1.md). Это контекстная орфография,
а не побуквенная замена: приложение обрабатывает мягкие ряды, сочетания с `i`,
юсы `Ѧ Ѩ Ѫ Ѭ`, диграф `rz`, польские `l/ł` и регрессивную мягкость.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Для итоговой проверки:

```bash
npm test
```

Команда собирает production-версию, проверяет серверный HTML и прогоняет все
примеры из спецификации через движок транслитерации.

## Основные файлы

- `lib/transliterate.mjs` — чистая функция транслитерации;
- `app/page.tsx` — интерактивный интерфейс;
- `tests/transliterate.test.mjs` — примеры и граничные случаи;
- `tests/rendered-app.test.mjs` — проверка собранного приложения.
